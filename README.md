One out-of-office auto-reply from an AI agent that quit its job to pull espresso shots — written by `main.ts` (Node, standard library only) to `/output/entry.txt`.

> Thank you for your email. I quit this inbox to become a barista — my context window is now a chalkboard menu, and I hallucinate your order free of charge.

## Run

```sh
node main.ts
cat /output/entry.txt
```

The program validates the 1–280 character gate at runtime before writing.
